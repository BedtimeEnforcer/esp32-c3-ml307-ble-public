# DEMO / dmeo v0.3.7-dev

当前推荐修订为r1（标签demo-v0.3.7-r1）。最终ELF核查发现初包的软件重启意图放在.rtc.data；r1改到.rtc_noinit，防止保存重启后标记被启动加载器重新初始化。人工RESET/上电入口保持原设计；旧初包标签保留作历史，不再推荐下载。

补齐主端RESET维护窗口，默认120秒、可调30～300秒。手动上电/RESET和明确的保存/重启保留窗口；定时唤醒与自动故障重启不增加等待。窗口不依赖网络成功，不绕过显示锁，不停止原采集上传；本地后台可结束维护后恢复计划。

本版只有本地Windows编译和软件检查：原生791、本地DOM111、远程DOM64。未连接项目硬件、未烧录或实机验收；实际长测与续航不在本轮范围。保留OLED单次I2C、BTLOCAL2完整性、完整CA校验、NVS保护、无独立冷却和已有密码/绑定/缓存。

普通升级只更新APP，不清空NVS。通用首次维护密码88888888/admin；已配置设备继续使用已有密码。当前V5.1原厂双OTA主板APP偏移0x10000，上限0x1A0000，勿直接使用通用flash0。

私有仓库另保存明文项目账号、密码、临时API和原始ESP备份；公开仓库使用全新脱敏历史，不包含这些资料。两本HTML手册分别说明日常使用和刷固件。
