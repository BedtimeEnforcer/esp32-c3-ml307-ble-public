# 前期选型与开发资料

| 模块 | 最终选择 | 接线与用途 |
|---|---|---|
| 主端 | ESP32-C3 + ML307 V5.1一体板 | UART GPIO3/4；GPIO5为电源键脉冲，不能当真正VBAT使能 |
| 从端 | ESP32-C3 USB直连开发板 | USB持续供电，WiFi/MQTT接收并重播，无深睡开关 |
| 显示 | 1.3寸SH1106 128×64四针I2C | 主屏SDA6/SCL7，从屏SDA4/SCL5；VDD3V3/GND，不套用七针SPI接法 |
| 电源 | 主端5V输出电池，从端USB | 前期评估5V3000mAh；电量为模型估算，未承诺实测续航 |

[完整前期选型快照](前期选型记录-20261110.md)记录了小智物联一体板、合宙C3、优信OLED及耐杰电池的选择。早期比较过NT26/RS485、TP4056和额外底板，最终用一体板减少连线。Air8000为独立比较，不是当前固件目标，旧方案不可与最终接线混用。

vendor包含C3两版原理图/尺寸、ML307的AT/MQTT/SSL/TCP/IP/硬件/升级等19本手册；schematics含V5.1供电、UART、按键、SIM电路分图。交互式BOM下载后离线打开。

图纸的MODEM_EN名称用于电源键控制脉冲，不是真正切断模组供电。GPIO9 BOOT不能直接唤醒本C3深睡；人工维护先RESET。
